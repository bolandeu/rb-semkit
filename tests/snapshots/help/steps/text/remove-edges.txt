
 Usage: semkit read {IN} remove-edges [OPTIONS]

 The characters to cut from the edges of each word (remove only).

 start: characters cut from the start of a word, any run of them.
 end: characters cut from the end of a word, any run of them.

 Characters inside a word stay («wi-fi»); a word of only those characters disappears. The result
 has single spaces, none at the edges.

 remove-edges removes what the matcher finds from the working column.

 Example: semkit read core.csv remove-edges --end '!' write out.csv

╭─ Options ────────────────────────────────────────────────────────────────────────────────────────╮
│ --start        <str>  characters cut from the start of a word, any run of them.                  │
│ --end          <str>  characters cut from the end of a word, any run of them.                    │
│ --as           NAME   Write the result to a new column NAME and keep the working column as it    │
│                       is.                                                                        │
│ --help                Show this message and exit.                                                │
