
 Usage: semkit read {IN} extract-positions [OPTIONS] [COUNT]

 The first characters of a phrase, or the last ones (remove and extract).

 count: how many characters.
 last: the last characters; by default the first.

 remove gives an empty cell when the phrase has that many characters or fewer; extract then gives
 the whole phrase.

 extract-positions keeps only what the matcher finds in the working column; an empty cell where it
 finds nothing.

 Example: semkit read core.csv extract-positions 2 write out.csv

╭─ Arguments ──────────────────────────────────────────────────────────────────────────────────────╮
│   COUNT      <int>  how many characters. The same as --count COUNT.                              │
╰──────────────────────────────────────────────────────────────────────────────────────────────────╯
╭─ Options ────────────────────────────────────────────────────────────────────────────────────────╮
│ --count        COUNT  how many characters.                                                       │
│ --last                the last characters; by default the first.                                 │
│ --as           NAME   Write the result to a new column NAME and keep the working column as it    │
│                       is.                                                                        │
│ --help                Show this message and exit.                                                │
