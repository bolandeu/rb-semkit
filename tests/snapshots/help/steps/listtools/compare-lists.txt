
 Usage: semkit read {IN} compare-lists [OPTIONS] [AGAINST]

 The phrases of two lists, by an operation.

 op: both (the phrases of the first list that are in the second), either (the first list, then the
 second), first (only in the first list), second (only in the second).
 kind: when two phrases are the same, as for dupes: exact, explicit, implicit or lemmas.
 second_column: the column of the phrases of the second list.

 A phrase keeps the spelling of its first occurrence and comes once; the order is the input order.
 Empty cells are never phrases.

 against: a file with the second list, one phrase per row; the file is read like `read` does. The
 phrases are in --second-column, by default the first text column of the file.

 The step takes the working column as the first list; the phrases it finds replace the current
 table, in a column of the same name.

 Example: semkit read phrases.csv compare-lists --against second.csv write out.csv
