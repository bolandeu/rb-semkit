
 Usage: semkit read {IN} parse-html [OPTIONS]

 The pages of the column as columns: text, links, all, main, title, description, h1. One row per
 page.

 A cell is the HTML of one page. A cell that is empty or has no tag (a plain text) gets empty
 columns. The columns are added right after the column of the pages.

 The page must hold its text in its HTML: a page built by JavaScript has none, so give the rendered
 HTML. Scripts, styles, noscript, templates and hidden elements are never counted.

 - text: the visible text without the text of links;
 - links: the text of links;
 - all: the text with the text of links;
 - main: the main content, without menus, header and footer;
 - title: the title of the page; description: its meta description; h1: its first H1.

 drop_noindex: leave out the text of <noindex> (the tag and the <!--noindex--> comments); by
 default it counts.
 drop_attributes: leave out the alt and title attributes; by default their text counts.

 The step reads the working column of HTML and adds the columns right after it; the rows stay.

 Example: semkit read --column html pages.csv parse-html write out.csv
