
 Usage: semkit read [IN] headings [OPTIONS]

 The headings of the pages, one row per heading in page order: url, order, level (H1-H6), text.

 A cell is the HTML of one page. The url comes from the column url, when the table has it and it is
 no column of the pages. The order starts at 1 for each page. A cell that is empty or has no tag
 gives no rows.

 The page must hold its text in its HTML: a page built by JavaScript has none, so give the rendered
 HTML.

 The step reads the working column of HTML; the table of the headings replaces the current one.

 Example: semkit read --column html pages.csv headings write out.csv
