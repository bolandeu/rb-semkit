
 Usage: semkit read {IN} bm25 [OPTIONS] [QUERY]

 Okapi BM25 of each text for `query`: a Series of scores, rounded to 4 decimals, with the index of
 `texts`.

 Terms are the lemmas without stopwords, on both sides; a term repeated in the query counts once.
 The length of a text is its number of terms. idf = ln((N - df + 0.5) / (df + 0.5) + 1); N, df and
 the average length are taken over the given texts, so to rank my text among the competitors pass
 all of them together. score = sum over the terms of idf x tf x (k1 + 1) / (tf + k1 x (1 - b + b x
 length / average length)). A text without a term of the query scores 0.

 The step takes each cell of the working column as a text and writes its score for the query to a
 new column <column>_bm25; to rank my text among the competitors, put all the texts in the working
 column.

 Example: semkit read core.csv bm25 купить write out.csv
