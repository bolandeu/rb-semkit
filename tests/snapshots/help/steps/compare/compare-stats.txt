
 Usage: semkit read {IN} compare-stats [OPTIONS] [COMPETITORS]

 The numeric metrics of sk.text_stats, mine against the competitors: a row per metric.

 mine: one text (a str).
 competitors: texts one per row (a Series, or a DataFrame with `column`).
 Columns: metric. mine. median, min, max: the metric over the competitors. delta: mine - median.
 verdict: 'below', 'within' or 'above', mine against median x (1 ± tolerance); when the median is
 0, 'within' if mine is 0, else 'above'. Numbers are rounded to 4 decimals. The only norm is the
 median.

 competitors: a file with the texts of the competitors, one per row, in its first text column; the
 file is read like `read` does.

 The step takes the working column as my text (its cells, one per line); the table of the
 comparison replaces the current one.

 Example: semkit read --whole mine.txt compare-stats --competitors competitors.csv write out.csv
