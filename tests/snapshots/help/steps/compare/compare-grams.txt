
 Usage: semkit read {IN} compare-grams [OPTIONS] [COMPETITORS]

 How the grams of my text differ from the competitors' texts: a row per gram met in any competitor.

 mine: one text (a str). competitors: texts one per row (a Series, or a DataFrame with `column`).
 The density of a gram in a text is its count / the words of that text; a competitor without the
 gram counts as 0. Grams are those of sk.ngrams (`n`, `lemmas`, `stopwords`).
 Columns: ngram. docs: competitors that hold it. docs_share: docs / competitors, 0..1. median, min,
 max: the density in the competitors. mine: its density in my text. verdict: 'below', 'within' or
 'above', mine against median x (1 ± tolerance); when the median is 0, 'within' if mine is 0, else
 'above'. Densities are rounded to 4 decimals. Sorted by median, biggest first, then ngram. The
 only norm is the median.

 competitors: a file with the texts of the competitors, one per row, in its first text column; the
 file is read like `read` does.

 The step takes the working column as my text (its cells, one per line); the table of the
 comparison replaces the current one.

 Example: semkit read core.csv compare-grams купить write out.csv
