
 Usage: semkit read [IN] classify-queries [OPTIONS] [AGAINST]

 The nearest phrase of the core for each query of a search query report, by meaning.

 threshold: the similarity from 0 to 1 a query needs to its nearest phrase to be a target.

 The columns: nearest_phrase (the first of two equally near), similarity (4 places) and target (yes
 when the similarity is at the threshold or above, else no); an empty cell gets none. No row is
 dropped.

 against: a file with the core, one phrase per row, in its first text column; the file is read like
 `read` does.
 model: the encoder, pulled once with `semkit models pull NAME`: e5-small, bge-m3, potion, or
 hf:<id> of a model of the Hugging Face hub. Without --threshold the step takes the threshold of
 the model; a hub model has none.

 The step takes the working column as the queries of a search query report and adds the columns
 nearest_phrase, similarity and target right after it; the rows stay.

 Example: semkit read phrases.csv classify-queries --against core.csv write out.csv
