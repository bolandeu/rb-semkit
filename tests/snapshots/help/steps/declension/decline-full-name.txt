
 Usage: semkit read [IN] decline-full-name [OPTIONS] [CASE]

 A full name «Фамилия Имя Отчество» put in the given case.

 The name «Иванов Сергей Петрович» in the genitive is «Иванова Сергея Петровича».

 case: "genitive", "dative", "accusative", "instrumental" or "prepositional".

 A full name that ends in «-на» or «-зы» is a woman's («Петрова Анна Ивановна» → «Петровой Анны
 Ивановны»). The surname declines by its ending («-ов», «-ин», «-ой», «-ская»…), the name and the
 patronymic as nouns; a surname in «-ых» or «-их» stays («Белых»), a man's surname in «-а» or «-я»
 declines («Глинка» → «Глинки»). The result has a capital in each word. An empty cell and a value
 that is not three words stay as they are.

 Example: semkit read --text "Иванов Сергей Петрович" decline-full-name genitive write -
 -> Иванова Сергея Петровича
 Example: semkit read --text "Петрова Анна Ивановна" decline-full-name instrumental write -
 -> Петровой Анной Ивановной

 The step rewrites the working column; with --as NAME it writes the result to a new column NAME.

│   CASE      <genitive|dative|accusative|instrumental|  "genitive", "dative", "accusative",       │
│             prepositional>                             "instrumental" or "prepositional". The    │
│                                                        same as --case CASE.                      │
