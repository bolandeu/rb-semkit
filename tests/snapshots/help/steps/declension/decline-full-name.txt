
 Usage: semkit read {IN} decline-full-name [OPTIONS] [CASE]

 A full name «Фамилия Имя Отчество» declined: «Иванов Сергей Петрович» genitive → «Иванова Сергея
 Петровича».

 case: "genitive", "dative", "accusative", "instrumental" or "prepositional". A full name that ends
 in «-на» or «-зы» is a woman's («Петрова Анна Ивановна» → «Петровой Анны Ивановны»). The surname
 declines by its ending («-ов», «-ин», «-ой», «-ская»…), the name and the patronymic as nouns; the
 result has a capital in each word. An empty cell stays empty; any other value that is not three
 words raises InvalidArguments.

 The step rewrites the working column; with --as NAME it writes the result to a new column NAME.

 Example: semkit read names.csv decline-full-name genitive write out.csv
