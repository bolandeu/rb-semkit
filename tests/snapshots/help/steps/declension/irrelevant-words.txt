
 Usage: semkit read [IN] irrelevant-words [OPTIONS] [WORD]

 The candidates for minus-words around a main word.

 The word «чехол» in «чехол для телефона» is a candidate for the main word «телефон».

 word: the main word, a noun in the nominative singular.

 A candidate is a word right before a preposition (or a pronoun) and a form of the main word in the
 case the preposition takes («для телефона», «на телефон»), when it is no stopword. Toponyms with
 their prepositions and buy markers are cut first («купить чехол для телефона в москве» → «чехол
 для телефона»). A table with a row per candidate in the order of first use: the columns word
 (lower case), uses (every phrase counts, repeats too) and examples (each distinct «word
 preposition form», joined by ", ").

 Example: semkit read --text "купить чехол для телефона" --text "чехол на телефон" irrelevant-words
 телефон write -
 -> чехол, 2, чехол для телефона, чехол на телефон

 The step reads the working column; the table replaces the current one, its column word is the
 working one.
