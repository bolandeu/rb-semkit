
 Usage: semkit read [IN] part-of-speech [OPTIONS]

 The part of speech of each word of a phrase, joined by a space.

 The codes are those of the bundled dictionary: n (noun), v (verb), a (adjective), p (participle),
 advb (adverb), prn (pronoun), prep (preposition), conj (conjunction), prt (particle), nv (as in
 the dictionary), and unkn for a word no rule gives a part of speech («кляк», «15»), so no code is
 empty.

 Example: semkit read --text "купить диван" part-of-speech write -
 -> купить диван, v n

 The step writes its result to a new column <column>_pos.

╭─ Options ────────────────────────────────────────────────────────────────────────────────────────╮
│ --as          NAME  Write the result to a new column NAME and keep the working column as it is.  │
│ --help              Show this message and exit.                                                  │
