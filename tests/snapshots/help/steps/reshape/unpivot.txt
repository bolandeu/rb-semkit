
 Usage: semkit read [IN] unpivot [OPTIONS]

 The kept columns stay; every other column turns into rows.

 Each kept row gives one row for each other column: the kept cells, the name of the column in
 name_column and its cell in value_column, in the order of the columns. A column that is not in the
 table is refused, naming the columns there are; so is keep with every column, and a name_column or
 value_column that a kept column has already.

 keep: the column to keep; repeat it for each next column.
 name_column: the column that holds the name of the unpivoted column.
 value_column: the column that holds the cell of the unpivoted column.

 Example: semkit read reshape/regions.csv unpivot --keep phrase write -
 -> диван, msk, 10; диван, spb, 4

 The step makes the value column the working column.

╭─ Options ────────────────────────────────────────────────────────────────────────────────────────╮
│ --keep                <str>  the column to keep; repeat it for each next column.                 │
│ --name-column         <str>  the column that holds the name of the unpivoted column.             │
│                              [default: column]                                                   │
│ --value-column        <str>  the column that holds the cell of the unpivoted column.             │
│                              [default: value]                                                    │
│ --help                       Show this message and exit.                                         │
