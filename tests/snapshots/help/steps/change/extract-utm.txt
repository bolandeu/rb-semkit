
 Usage: semkit read [IN] extract-utm [OPTIONS] [TAG]

 The value of a UTM tag of the URL, URL-decoded.

 «?utm_source=%D0%AF%D0%BD%D0%B4%D0%B5%D0%BA%D1%81» → «Яндекс», «+» as a space. Only the part
 before «#» is searched; the name counts in any case; the first tag of that name wins; no such tag
 gives an empty cell.

 tag: the name of the tag without utm_: source, medium, campaign, term or content.

 Example: semkit read --text "https://site.ru/?utm_source=ya&utm_medium=cpc&id=5" extract-utm
 medium write -
 -> cpc

 The step rewrites the working column; with --as NAME it writes the result to a new column NAME.

╭─ Arguments ──────────────────────────────────────────────────────────────────────────────────────╮
│   TAG      <source|medium|campaign|term|content>  the name of the tag without utm_: source,      │
│                                                   medium, campaign, term or content. The same as │
│                                                   --tag TAG.                                     │
╰──────────────────────────────────────────────────────────────────────────────────────────────────╯
╭─ Options ────────────────────────────────────────────────────────────────────────────────────────╮
│ --tag         TAG   the name of the tag without utm_: source, medium, campaign, term or content. │
│ --as          NAME  Write the result to a new column NAME and keep the working column as it is.  │
│ --help              Show this message and exit.                                                  │
╰──────────────────────────────────────────────────────────────────────────────────────────────────╯
