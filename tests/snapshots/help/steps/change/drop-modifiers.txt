
 Usage: semkit read [IN] drop-modifiers [OPTIONS]

 The phrase without the «+» or «!» of its stopwords, in any case.

 «+купить +в !москве +для дачи» → «+купить в !москве для дачи». The words are joined by one space.

 Example: semkit read --text "+купить +в !москве +для дачи" drop-modifiers write -
 -> +купить в !москве для дачи

 The step rewrites the working column; with --as NAME it writes the result to a new column NAME.

╭─ Options ────────────────────────────────────────────────────────────────────────────────────────╮
│ --as          NAME  Write the result to a new column NAME and keep the working column as it is.  │
│ --help              Show this message and exit.                                                  │
╰──────────────────────────────────────────────────────────────────────────────────────────────────╯
