
 Usage: semkit read [IN] split-digits [OPTIONS]

 A separator between digits and the text glued to them: «iphone13pro» → «iphone 13 pro». Digits and
 text already apart stay as they are; a size N×M (the x latin or cyrillic, in any case) stays whole
 («диван140х200» → «диван 140х200»).

 sep: the separator; with "|" «a1b22» → «a|1|b|22».

 The step rewrites the working column; with --as NAME it writes the result to a new column NAME.

 Example: semkit read core.csv split-digits write out.csv

╭─ Options ────────────────────────────────────────────────────────────────────────────────────────╮
│ --sep         <str>  the separator; with "|" «a1b22» → «a|1|b|22». [default:  ]                  │
│ --as          NAME   Write the result to a new column NAME and keep the working column as it is. │
│ --help               Show this message and exit.                                                 │
╰──────────────────────────────────────────────────────────────────────────────────────────────────╯
