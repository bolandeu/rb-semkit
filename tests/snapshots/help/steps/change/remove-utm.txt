
 Usage: semkit read {IN} remove-utm [OPTIONS]

 The URL without its UTM tags, the parameters whose name starts with «utm_» in any case:
 «https://site.ru/?UTM_Source=ya&utm_medium=cpc&id=5#top» → «https://site.ru/?id=5#top». The rest
 of the query stays after one «?» and between single «&»; with no parameter left, the «?» goes too.

 The step rewrites the working column; with --as NAME it writes the result to a new column NAME.

 Example: semkit read core.csv remove-utm write out.csv

╭─ Options ────────────────────────────────────────────────────────────────────────────────────────╮
│ --as          NAME  Write the result to a new column NAME and keep the working column as it is.  │
│ --help              Show this message and exit.                                                  │
╰──────────────────────────────────────────────────────────────────────────────────────────────────╯
