
 Usage: semkit read {IN} sort-words [OPTIONS]

 The words of the phrase sorted by their character codes, joined by one space: digits, then latin
 capitals, latin small letters, cyrillic capitals, cyrillic small letters; «Ё» before «А» and «ё»
 after «я».

 The step rewrites the working column; with --as NAME it writes the result to a new column NAME.

 Example: semkit read core.csv sort-words write out.csv

╭─ Options ────────────────────────────────────────────────────────────────────────────────────────╮
│ --as          NAME  Write the result to a new column NAME and keep the working column as it is.  │
│ --help              Show this message and exit.                                                  │
╰──────────────────────────────────────────────────────────────────────────────────────────────────╯
