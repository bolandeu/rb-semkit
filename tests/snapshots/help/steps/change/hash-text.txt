
 Usage: semkit read [IN] hash-text [OPTIONS]

 The hash of the text as lower-case hex, of its UTF-8 bytes.

 An empty text has a hash too (md5 «d41d8cd98f00b204e9800998ecf8427e»).

 algorithm: "md5" or "sha256".

 Example: semkit read --text "купить диван" hash-text write -
 -> b85908bb0ec978af96f2ce5a66e0b4a3

 The step rewrites the working column; with --as NAME it writes the result to a new column NAME.

╭─ Options ────────────────────────────────────────────────────────────────────────────────────────╮
│ --algorithm        <md5|sha256>  "md5" or "sha256". [default: md5]                               │
│ --as               NAME          Write the result to a new column NAME and keep the working      │
│                                  column as it is.                                                │
│ --help                           Show this message and exit.                                     │
╰──────────────────────────────────────────────────────────────────────────────────────────────────╯
