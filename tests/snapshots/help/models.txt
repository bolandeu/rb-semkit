
 Usage: semkit models [OPTIONS] COMMAND [ARGS]...

 Models of the steps by meaning and by words (encoders, word data): pull one once into the cache,
 list them, remove one. The cache is the system cache, or the folder of the config key models.dir.

╭─ Options ────────────────────────────────────────────────────────────────────────────────────────╮
│ --help          Show this message and exit.                                                      │
╰──────────────────────────────────────────────────────────────────────────────────────────────────╯
╭─ Commands ───────────────────────────────────────────────────────────────────────────────────────╮
│ pull    Download a model once into the cache, at its pinned revision, and check the checksum of  │
│         each file.                                                                               │
│ list    Every model semkit knows (encoders and word data) and every hub model pulled: its repo,  │
│         revision, whether it is pulled, its size in bytes, its default threshold and its folder. │
│ remove  Remove a model from the cache.                                                           │
╰──────────────────────────────────────────────────────────────────────────────────────────────────╯
