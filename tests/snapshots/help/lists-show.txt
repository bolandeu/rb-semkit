
 Usage: semkit lists show [OPTIONS] {name}

 Show the items of a word list, one per line.

 An unknown name exits 2 with the closest names.

 Example: semkit lists show @minus/cheap

╭─ Arguments ──────────────────────────────────────────────────────────────────────────────────────╮
│ *    name      <str>  The name of the list, as niche/mebel or @niche/mebel (see `lists`).        │
│                       [required]                                                                 │
╰──────────────────────────────────────────────────────────────────────────────────────────────────╯
╭─ Options ────────────────────────────────────────────────────────────────────────────────────────╮
│ --json           Emit machine-readable JSON output.                                              │
│ --quiet          Suppress non-essential output.                                                  │
│ --help           Show this message and exit.                                                     │
╰──────────────────────────────────────────────────────────────────────────────────────────────────╯
