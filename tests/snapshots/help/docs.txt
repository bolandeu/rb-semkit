
 Usage: semkit docs [OPTIONS]

 Write the help of every command and step as one document for people: OpenCLI with the commands at
 the root.

 The document follows the help standard: each command has its summary, description and examples
 apart, each option ends with its default and allowed values, and each step page shows how to give
 the step its input. The same version writes the same bytes. A viewer such as InSpectra renders it
 as HTML.

 Example: semkit docs --out docs.json

╭─ Options ────────────────────────────────────────────────────────────────────────────────────────╮
│ --out          FILE  Write the document to FILE (replaced when it exists); by default to stdout. │
│ --json               Emit machine-readable JSON output.                                          │
│ --quiet              Suppress non-essential output.                                              │
│ --help               Show this message and exit.                                                 │
╰──────────────────────────────────────────────────────────────────────────────────────────────────╯
