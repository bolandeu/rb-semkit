
 Usage: semkit read [IN] write [OPTIONS] {OUT}

 Write the current table to OUT: the last step of a pipeline.

 The file is written whole or not at all: a failed step or write leaves it as it was. With
 --dry-run nothing is written. A closed output (`| head`) ends the pipeline quietly.

 --columns and --rename choose, order and name the output columns; a name the table lacks, or two
 columns with one name, is refused (exit 2) with the columns there are.

 Example: semkit read core.csv dupes --kind exact --action drop write out.csv --overwrite

 Chosen columns, renamed: semkit read phrases.csv nearest --to Q write - --columns
 phrase,similarity --rename similarity=сходство

╭─ Arguments ──────────────────────────────────────────────────────────────────────────────────────╮
│ *    OUT      <str>  The file to write, its format by its extension; '-' for JSONL on stdout.    │
│                      [required]                                                                  │
╰──────────────────────────────────────────────────────────────────────────────────────────────────╯
╭─ Options ────────────────────────────────────────────────────────────────────────────────────────╮
│ --overwrite                   Replace OUT when it exists.                                        │
│ --columns          NAME,NAME  The columns to write, in this order: a comma list, repeatable. By  │
│                               default all, as the steps made them.                               │
│ --rename           OLD=NEW    Write the column OLD under the name NEW, repeatable; applied after │
│                               --columns, so OLD is a name the selection keeps. A swap a=b, b=a   │
│                               is allowed.                                                        │
│ --help                        Show this message and exit.                                        │
╰──────────────────────────────────────────────────────────────────────────────────────────────────╯
