
 Usage: semkit read {IN} write [OPTIONS] {OUT}

 Write the current table to OUT: the last step of a pipeline.

 The file is written whole or not at all: a failed step or write leaves it as it
 was. With --dry-run nothing is written.

 Example: semkit read core.csv dupes --kind exact --action drop write out.csv --overwrite

╭─ Arguments ──────────────────────────────────────────────────────────────────────────────────────╮
│ *    OUT      <str>  The file to write, its format by its extension; '-' for JSONL on stdout.    │
│                      [required]                                                                  │
╰──────────────────────────────────────────────────────────────────────────────────────────────────╯
╭─ Options ────────────────────────────────────────────────────────────────────────────────────────╮
│ --overwrite          Replace OUT when it exists.                                                 │
│ --help               Show this message and exit.                                                 │
╰──────────────────────────────────────────────────────────────────────────────────────────────────╯
