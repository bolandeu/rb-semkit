
 Usage: semkit run [OPTIONS] COMMAND [ARGS]...

 Run a workflow: a named chain of semkit's own steps, kept so that a frequent chain runs by its
 name.

 The workflows are the commands below: the bundled ones and the project's own, a file NAME.toml in
 .rb_semkit/workflows/ (one of the same name overrides the bundled one). The former folder
 .rb_semkit/scenarios/ is read too; a name in both: workflows/ wins. 'run NAME [IN | --text TEXT…]
 [--set NAME=VALUE…] [write OUT]' reads the input as read does, runs the steps of the workflow as
 one read pipeline and writes the result; without write it prints a table, as read does. --set
 NAME=VALUE fills a parameter of the workflow, --set STEP.OPTION=VALUE an option of one of its
 steps. 'run NAME --help' shows its parameters with their defaults and its steps.

 Example: semkit run intent-synonyms --text "растаможка авто"
