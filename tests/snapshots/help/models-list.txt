
 Usage: semkit models list [OPTIONS]

 Every model semkit knows (encoders and word data) and every hub model pulled: its repo, revision,
 whether it is pulled, its size in bytes, its default threshold and its folder.

 Example: semkit models list --json

╭─ Options ────────────────────────────────────────────────────────────────────────────────────────╮
│ --json           Emit machine-readable JSON output.                                              │
│ --quiet          Suppress non-essential output.                                                  │
│ --help           Show this message and exit.                                                     │
╰──────────────────────────────────────────────────────────────────────────────────────────────────╯
