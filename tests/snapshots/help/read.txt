
 Usage: semkit read [OPTIONS] [IN] COMMAND [ARGS]...

 Read a table, run the steps in the order written, write the result: one pipeline.

 Each step works on the current table. A change step rewrites the working column (with --as NAME it
 writes a new column NAME, which the next steps work on), a filter keeps or drops rows, a report
 (n-grams) makes its table the current one and its first text column the working one. After each
 step one line goes to stderr: the step, the rows before and after it, the cells it changed; the
 last line says how many rows went where. A pipeline that ends without write prints the result as a
 table in the terminal; with --json, or when stdout is not a terminal, it writes JSONL to stdout as
 `write -` does. Every step and option is checked before the input is read.

 Columns are read with the types of the file: numbers stay numbers, a text column is text and its
 empty cell an empty text. A column of numbers with spaces around a cell is numbers too. A column
 of numbers picked as the working column is text for the step and is written back as numbers. An
 option that takes items takes a comma list 'a,b', @FILE (one item per line, or the first column of
 a table without its header) or @NAME of a list (@stop/semtools, @minus/cheap…; `semkit lists`
 shows them all). `semkit read IN STEP --help` shows a step.

 Example: semkit read core.csv remove-words --items купить dupes --kind lemmas --action drop write
 out.csv

 Phrases from the command line, the result as a table: semkit read --text "растаможка авто"
 synonym-candidates --all

╭─ Arguments ──────────────────────────────────────────────────────────────────────────────────────╮
│   IN      <str>  The table to read: a file of any format dataio reads, or '-' for JSONL on       │
│                  stdin. Left out with --text.                                                    │
╰──────────────────────────────────────────────────────────────────────────────────────────────────╯
╭─ Options ────────────────────────────────────────────────────────────────────────────────────────╮
│ --text           TEXT   A phrase from the command line, repeatable: the table has one column     │
│                         phrase and a row for each --text, in the order given. IN is then left    │
│                         out.                                                                     │
│ --column         <str>  The working column the steps read and change; by default the first text  │
│                         column.                                                                  │
│ --whole                 Read a text file as one cell of the column text (an article).            │
│ --trace          FILE   Write every cell a step changes and every row it drops to FILE as JSONL: │
│                         row (1 is the first row under the header), step, column, before, after.  │
│                         An existing FILE needs --overwrite.                                      │
│ --json                  Emit machine-readable JSON output.                                       │
│ --quiet                 Suppress non-essential output.                                           │
│ --dry-run               Read and run every step, print the summary, write nothing.               │
│ --help                  Show this message and exit.                                              │
