# Справочники зашиты в пакет и лежат в git

Словарь лемм (marisa-trie, ~10 МБ), списки маркеров, таблицы склонения и стоп-слова собирает `scripts/build_data.py` из материалов надстройки !SEMTools; собранные файлы коммитятся и ставятся вместе с пакетом, без загрузки при установке и без обновления списков (версия заморожена, свои списки — параметром). Данные принадлежат автору !SEMTools: репозиторий приватный, данные никогда не публикуются.

Рассмотренные варианты: SQLite (37.8 МБ), gzip TSV в dict (~200 МБ памяти), сборка при установке.
