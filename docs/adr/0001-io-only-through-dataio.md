# Ввод-вывод только через dataio

semkit сам не читает и не пишет файлы: библиотека принимает и возвращает `pandas.Series` / `DataFrame`, а CLI читает и пишет через `rb_dataio` (обязательная зависимость пакета с E-003: CLI — основной способ работы человека и агента; закреплена тегом в репозитории dataio на homeserver; поток между командами — JSONL). Так форматы (xlsx, csv, Google-таблицы, parquet) живут в одном инструменте, а semkit остаётся чистой обработкой фраз. Договор с dataio — `docs/plan.md` §3.
