# Ввод-вывод только через dataio

semkit сам не читает и не пишет файлы: библиотека принимает и возвращает `pandas.Series` / `DataFrame`, а CLI читает и пишет через `rb_dataio` (дополнение `[io]`, закреплено тегом; поток между командами — JSONL). Так форматы (xlsx, csv, Google-таблицы, parquet) живут в одном инструменте, а semkit остаётся чистой обработкой фраз. Договор с dataio — `docs/plan.md` §3.
