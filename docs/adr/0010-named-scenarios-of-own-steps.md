# Именованные сценарии — только из шагов semkit

ADR 0008 говорил «готовых сценариев нет». Человек (2026-10-18) решил иначе: `semkit run NAME` запускает именованную цепочку собственных шагов semkit (встроенную или из папки проекта, TOML с параметрами и их значениями по умолчанию), видна в `run --help` и `semkit docs`. Сценарий — запись цепочки, а не новый составной шаг: шаги остаются атомарными кирпичиками, каждый вызывается и сам. Флоу с другими CLI (bukvarix, wordstat, serp) собирается снаружи semkit.

Статус: accepted; уточняет 0008.

Рассмотренные варианты: только shell-функции у человека (не видны агентам и в справке); составные шаги в коде (нарушают атомарность шагов); сценарии с вызовом других CLI (semkit стал бы оркестратором).
