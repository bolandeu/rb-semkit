# Решения (ADR)

Файл `NNNN-slug.md`, номер — следующий за наибольшим. Шаблон:

```md
# Короткое название решения

Одно-три предложения: контекст, что решили и почему.
```

Необязательно, только если полезно: `Статус` (proposed | accepted | deprecated | superseded by NNNN),
`Рассмотренные варианты`, `Последствия`.

Записывать решение, только когда верны все три:
1. его трудно отменить;
2. без контекста оно удивит читателя;
3. был реальный выбор между вариантами.
