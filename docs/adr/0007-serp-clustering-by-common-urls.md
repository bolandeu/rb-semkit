# Кластеры по готовой выдаче — мягкие и жёсткие, по числу общих URL

semkit кластеризует таблицу выдачи, которую ему дали (`cluster_serp`), и сам выдачу не собирает: её собирает другой инструмент. Фразы группируются по числу общих URL в топе стандартными методами: мягким (кластер растёт вокруг центра) и жёстким (фраза входит в кластер, только если делит нужное число URL с каждым его членом). Метод надстройки (позиционный счёт и компоненты связности) не переносим: он сцепляет A и C через B без единого общего URL; запись отхода — в ADR 0005.

Рассмотренные варианты: перенос метода надстройки как есть; кластеры по эмбеддингам (вне области semkit). Пары фраз ищутся через обратный индекс URL → фразы, а не перебором всех пар.
