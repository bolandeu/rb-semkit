# Морфология: словарь надстройки, затем pymorphy3, без mystem

Леммы и части речи берутся из словаря надстройки; слово, которого там нет, — из pymorphy3 (обычная зависимость, решение 2026-10-16); не знает и он — суффиксная таблица `lemmSuf`. Склонение без режимов: склоняют таблицы надстройки; pymorphy3 даёт одушевлённость и дефисные существительные. mystem не берём: закрытая внешняя программа, не ставится через uv, вызывается через процесс и временные файлы.
