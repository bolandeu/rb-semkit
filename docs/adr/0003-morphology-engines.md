# Морфология: свой словарь по умолчанию, pymorphy3 — дополнение, без mystem

Леммы и части речи по умолчанию берутся из словаря надстройки (без зависимостей); pymorphy3 — дополнение `[pymorphy]`. Склонение в режиме `auto`: pymorphy3 установлен и знает слово → pymorphy3, иначе таблицы надстройки; режимы `table` и `pymorphy` — явно. mystem не берём: закрытая внешняя программа, не ставится через uv, вызывается через процесс и временные файлы.
