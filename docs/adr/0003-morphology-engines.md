# Морфология: словарь надстройки, затем pymorphy3, без mystem

Леммы и части речи берутся из словаря надстройки; слово, которого там нет, — из pymorphy3 (обычная зависимость, решение 2026-10-16); не знает и он — суффиксная таблица `lemmSuf`. Склоняют таблицы надстройки; pymorphy3 даёт им только одушевлённость и род существительного для винительного падежа и форму слова через дефис; режимов склонения (`auto`, `table`, `pymorphy`) нет (решение 2026-10-17). mystem не берём: закрытая внешняя программа, не ставится через uv, вызывается через процесс и временные файлы.

Словарь надстройки отвечает первым и местами ошибается («кафе» → «кафа», «ширина» → «ширин», «временного» → «временной»); правило «pymorphy3 главнее словаря» не берём: pymorphy3 ошибается на других словах («мини» → «минь», «аскона» → «аскон») и сдвинул бы леммы всего ядра. Неверные строки словаря и таблиц склонения правим данными: `scripts/build_parts/morph.toml` и `scripts/build_parts/declension.toml` — словоформа (или строка таблицы), верная форма, причина; сборка ставит их вместо строк надстройки и пишет в манифест данных. Лемма от pymorphy3 пишется с ё, только если ё есть в слове («вперед» → «вперед»), как в словаре. Слово, которому ни одно правило не дало часть речи, получает код `unkn`. Винительный падеж по одушевлённости: «диван», но «кота»; слово через дефис: «дивана-кровати», «интернет-магазина».
