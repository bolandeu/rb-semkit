# VBA надстройки — источник переноса, а не часть продукта

semkit повторяет функции надстройки !SEMTools и даёт CLI для агентов и людей. VBA нужен только сейчас, пока из него берутся алгоритмы (ADR 0005), и после переноса с ним дела не имеем (решение Человека 2026-10-17). Поэтому API, справка, docstring и CLI описывают поведение словами пользователя, без имён обработчиков и номеров строк VBA. Ссылки на VBA живут только в материалах переноса: справочники `docs/vba/`, файлы случаев сверки `tests/conformance/cases/` и отходы в ADR 0005.
