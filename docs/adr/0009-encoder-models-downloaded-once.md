# Модели векторов скачиваются одной явной командой в кэш системы

semkit не скачивает данные, но модель векторов (encoder) нужна на диске: `semkit models pull NAME` один раз кладёт её в `platformdirs.user_cache_path("semkit")/models` (macOS `~/Library/Caches/semkit/models`, Linux `$XDG_CACHE_HOME` или `~/.cache/semkit/models`), с фиксированной ревизией и проверкой контрольной суммы; `models.dir` в конфиге задаёт другое место. Шаги конвейера ничего не качают: без модели — ошибка с готовой командой `models pull`. Шаги по смыслу дают кандидатов в колонках и сами строк не удаляют.

Рассмотренные варианты: скачивание при первом запуске шага (тихая загрузка в конвейере ломает офлайн и предсказуемость); путь к модели, скачанной вручную (лишняя работа человеку; остаётся как `models.dir`).
