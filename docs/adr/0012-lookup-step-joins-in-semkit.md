# Шаг lookup соединяет таблицы в самом semkit, не через dataio join

Человек (2026-10-23) решил: шаг `lookup` подтягивает столбцы другой таблицы к текущей таблице цепочки собственным кодом semkit (в памяти). `dataio join` работает только с файлами, а его библиотека не даёт соединения таблиц в памяти. Другую таблицу шаг читает через dataio, как и любой ввод semkit.

Статус: accepted.

Рассмотренные варианты: вынести `join` в библиотеку dataio и сделать в semkit тонкую обёртку (одна реализация на оба инструмента, но шаг ждёт выпуска dataio, и dataio выходит за ввод-вывод); вызывать CLI `dataio join` через файлы (выход из цепочки).
