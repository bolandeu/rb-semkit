# CLI — конвейер из цепочки шагов-подкоманд

Одна команда — конвейер: `semkit read IN шаг … шаг write OUT`, шаги — подкоманды в цепочке (как `chain` в Click), выполняются в порядке записи; каждая функция библиотеки — шаг, порождённый из её сигнатуры и docstring по одной таблице соответствий. Отчётный шаг (n-граммы, метрики, кластеры) делает свою таблицу текущей; сводка по шагам — в stderr, подробный журнал — `--trace FILE`. Готовых сценариев нет: их собирает человек или агент.

Рассмотренные варианты: шаги-опции с порядком из argv (Typer порядок разных опций теряет — свой разбор); мини-язык в одной строке (свой парсер, без `--help` и `describe` по шагу).
