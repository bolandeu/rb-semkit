# Повторяем алгоритмы VBA надстройки, явные дефекты исправляем

Эталон поведения — алгоритмы из исходников VBA !SEMTools, а не «как правильно» с нуля и не прогон надстройки в Excel. Отступаем от VBA только там, где у неё дефект или побочный эффект Excel (решения Человека 2026-10-16): ё = е при сравнении; стоп-слова без учёта регистра; пустые ячейки никогда не дубли; фраза делится по любым пробелам, двойных пробелов в результатах нет; леммы в нижнем регистре; n-граммы сортируются по убыванию счёта; маркеры — в написании списка, через «, ». Регулярные выражения понимают кириллицу: классы \w, \b, \d в режиме Unicode, а не ASCII, как в VBScript (решение Человека 2026-10-17). Украинский текст (chars('ua')) — по буквам і ї є ґ, а не по 31 элементу `fua`: окончания вроде «ати » ловят русские слова («кровати»). Явное улучшение там, где Python может больше VBA (как регулярные выражения с кириллицей), делаем без отдельного вопроса и записываем сюда (решение Человека 2026-10-17). Как в VBA: n-граммы считают вхождения; биграммы «w1+w2» без удаления стоп-слов по умолчанию. Эталоны: `/Users/bolandau/Work/_sandbox/semtools/reference/semkit_reference.xlsx`.
