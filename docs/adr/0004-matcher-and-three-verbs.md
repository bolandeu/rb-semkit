# Один шаблон — три глагола: find, remove, extract

Надстройка группирует команды по действию (около 60 пунктов «найти / удалить / извлечь X»). semkit делает объект-шаблон (`words`, `chars`, `regex`, `markers`, `stopwords`, `pos`…) и три глагола над ним: `find` → маска `bool`, `remove` → очищенный текст, `extract` → найденная часть. Новый шаблон сразу работает со всеми тремя глаголами; 60 отдельных функций не нужны.
