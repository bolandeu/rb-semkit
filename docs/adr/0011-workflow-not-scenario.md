# Именованная цепочка шагов называется workflow, не сценарий

Человек (2026-10-20) решил: то, что ADR 0010 назвал сценарием, — это workflow (воркфлоу). Устройство то же, что у workflow в GitHub/Gitea Actions: именованный файл, шаги по порядку, входные параметры со значениями по умолчанию, запуск по имени. «Сценарий» читается как тест-кейс, «run» — действие, а не вещь. Команда остаётся `semkit run NAME`. Папки: `src/rb_semkit/data/workflows/` и `.rb_semkit/workflows/`; старая `.rb_semkit/scenarios/` ещё читается, чтобы сохранённые файлы не сломались.

Статус: accepted; меняет название из 0010, не решение.

Рассмотренные варианты: scenario (оставить); run (путается с командой); recipe и preset (recipe уже под запретом для конвейера, preset звучит как набор настроек, а не цепочка шагов).
