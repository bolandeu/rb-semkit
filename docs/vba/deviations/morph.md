# Отходы области morph от VBA

Леммы, части речи и словоформы (`docs/vba/analysis.md` §1.4, §1.5, §2). Каждое правило: как было в VBA и почему иначе (ADR 0005). Случай сверки цитирует правило дословно.

- **Неверная лемма словаря исправлена.** В VBA (`aaa`, стр. 1354) лемма берётся из словаря `lemms.tsv` как есть, а у части слов там чужая лемма: «кафе» → «кафа», «ширина» → «ширин», «подростка» → «подростковый», «временного» → «временной», «раскладывается» → «раскладывающийся»; у части слов там чужая часть речи: «лучше» — n, «покрывало» — v. Исправления записаны в `scripts/build_parts/morph.toml`: словоформа, её лемма и часть речи, причина; сборка данных ставит их вместо строк словаря (ADR 0003).
- **Слово без части речи получает код unkn.** В VBA (`oa`, стр. 2208) слово, которого нет в словаре, возвращается как свой же код («кляк» → «кляк»), а пустое слово между двумя пробелами — пустой код. Теперь у каждого слова есть код: n, v, a, p, advb, prn, prep, conj, prt, nv или unkn, и двойных пробелов в результате нет.
- **Прилагательное с «не-» — прилагательное.** В словаре `lemms.tsv` около 280 слов на «не-» с кодом n, хотя слово без «не» — прилагательное («нераскладной», «неактивна»). Такое слово получает код a, и «Все что склоняется» склоняет его как прилагательное: «нераскладном диване».
- **Исходное слово не входит в словоформы.** В VBA (`––aa`, стр. 380) первая строка результата — само исходное слово, а затем все формы его леммы, так что слово стоит в результате дважды («диван | диван | дивана…»). Теперь результат — только другие формы, без исходного слова (ё = е): «диван» → «дивана, диванам…».
