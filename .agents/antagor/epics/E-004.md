## Problem

An end-to-end check of v0.1.20 on a real Bukvarix core and real page texts (docs/plans/e2e-quality.md) found that counting, dupes, n-grams, clusters and list filters are right, but the morphology gives wrong Russian (lemmas, the accusative, plurals, full names), typo correction breaks correct phrases, text rules split and count words differently from step to step, the minus lists miss inflected words, and the CLI guide, help and errors disagree with what the CLI does; --as can overwrite a column silently.

## Goal

Every finding of docs/plans/e2e-quality.md is fixed, decided in an ADR or the help, or recorded as not taken; a checked-in end-to-end run on a real core and a real text recounts the results independently and is part of the gate.

## Acceptance (Given–When–Then)

- Given the lemmas and the declension forms found wrong in the check (кафе, мини, ширина, временного, кожаный диван accusative, угловые диваны, the full names), When the library runs them, Then it gives the correct Russian form, and each is a conformance case of its area
- Given a plural phrase of a core, When decline runs to any case, Then the phrase declines in the plural
- Given the 2000 phrases of the sofa core, When is-typo and typo-correction run, Then no correct phrase is marked or rewritten (a real typo still is)
- Given a minus list of lemmas, When drop-words or drop-phrases runs with matching by lemmas, Then a phrase with any form of a list word is dropped («дешевые диваны», «со скидкой»)
- Given a text, When split-text, text-stats, coverage and compare-grams run, Then they split it into words the same way, a dash between subject and predicate and an abbreviation point do not cut a phrase, and single-letter abbreviations are no lemmas
- Given --as NAME of an existing column, When the pipeline starts, Then it refuses before reading the input, naming the column; a step after --as can work on the new column
- Given semkit --ai, describe --json and each step's --help, When an agent follows them, Then every flag, envelope field, example and error they name exists and runs as written on the shipped data; every enum option lists its values
- Given a wrong input (a missing file of any option, CSV on stdin, a bad value of any option), When the pipeline runs, Then it exits 2 before reading the input, naming the step and the flag, with a CLI action
- Given a pipeline written to stdout and cut by head, When head closes the pipe, Then semkit exits quietly
- Given an integer column with an empty cell in xlsx or jsonl, When read, Then it stays integer
- Given the e2e fixtures (a real core and a real text), When the gate runs, Then the ten runs of the check are recomputed independently and agree

## Implementation decisions

- Core: the lemmatizer chain (bundled dictionary, pymorphy3, suffix table) gets a correction for the dictionary's wrong lemmas; ADR 0003 records the rule
- Core: declension of phrases (case agreement of adjective and noun, animacy, plural, hyphenated compounds); full names
- Core: one word splitter shared by split_text, text_stats, coverage and compare-grams; split_text rules for dashes, abbreviations, numbers
- Core: the typo provider gets a frequency or dictionary guard so a known word form is no typo
- CLI: the step table exposes the matchers' lemma matching; --as checks and the working column after --as; error mapping of dataio and option errors to exit 2 with the step and the flag
- CLI: the help generator gives every option its own text and its accepted values (describe --json too); the guide is checked against the CLI by a test
- Tests: e2e fixtures (a Bukvarix core, an ost-term text) with an independent recount of the ten runs

## Test seams

- the library: import rb_semkit as sk, through the conformance case files of each area
- the CLI: semkit read IN steps… write OUT, through CliRunner
- the e2e run: the real-core fixtures recomputed independently, in the gate

## Out of scope

- Fetching texts or SERPs (another tool); embeddings
- A new morphology engine (mystem or a model): only the dictionary, pymorphy3 and the tables of ADR 0003
- Real competitor texts: compare-grams is checked for its maths
